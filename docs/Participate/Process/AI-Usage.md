# AI Usage

We generally _don't forbid_ the use of AI tools to generate code for your contributions.
However, we reserve the right to close pull requests without further explanation if

- they involve excessive iterations in review
- they do not resolve the issue 
- they "progress" in the wrong direction
- they contain unnecessarily complex code or breaking changes

ultimately causing a significant increase in review effort that is just not worth the time.

We encourage you to use AI tools _only_ to find bugs and improve the quality of the code instead of generating new features.

# Disclosure

BetonQuest is maintained by humans without excessive use of generative AI.

# Contributors

Contributors that use generative AI for their contributions:

- should disclose this fact in their pull request
- are not eligible to be viewed as a contributor in the context of BetonQuest besides being listed in the GitHub contributors
