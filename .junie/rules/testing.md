# Testing Conventions
- **Frameworks:** JUnit 5 and Mockito.
- **Method Naming:** Test methods must be named using `snake_case`.
- **Isolation:** Tests should be independent and not rely on execution order.
- **Precision:** Tests should be precise and not overly verbose. They don't need to be exhaustive.
- **Coverage:** Every new feature or bug fix must be accompanied by relevant unit tests.
- **Mocking:** Mocking should be done using Mockito.
- **Integration Tests:** Integration tests are suffixed with `IT`.
