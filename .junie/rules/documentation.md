# Documentation Rules

These rules apply to the creation and editing of documentation in the `docs/` directory.

## Principles
- **Language:** The entire documentation must be written in **English**, preferably simpler English.
- **Consistency:** Strictly follow the guidelines in `docs/Participate/Process/Docs/Style-Definitions.md`.
- **Path References:** References to other documentation pages should use relative paths.
- **Snippets:** Use the provided snippets for repeating elements like context requirements.
- **Check Links:** Ensure that all relative links work.
- **Avoid Redundancy:** Prefer referencing existing explanations in other documentation files.
- **Consistency:** Ensure that all documentation is consistent with the rest of the project and does match the
  functionality of the code.
- **Reference Lists Sorting:** Elements must always be inserted into their respective lists in **alphabetical** order.
